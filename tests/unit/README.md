# Unit Tests

Unit tests for individual components, functions, and modules.

## Structure

Mirror the source code structure here. For example:

```
src/
  components/
    Button.ts
  utils/
    helpers.ts

tests/unit/
  components/
    Button.test.ts
  utils/
    helpers.test.ts
```

## Guidelines

- Test one unit of functionality at a time
- Mock external dependencies
- Use descriptive test names
- Group related tests using `describe` blocks
- Aim for high code coverage
